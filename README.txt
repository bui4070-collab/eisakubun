■ しくみ
 ・おんがくは 「ばめん」が かわる たびに おなじ ものがたりの 曲へ。ミュートボタン・スキップ・おわりで ちゃんと とまる
 ・音が そろうまで（はじめて ひらく とき 数びょう）は これまでの ピコピコ おんがくが ながれ、そろったら きりかわる
 ・つぎの しょうが とどく まえに 音を よみこんで おくので、2かいめ いこうは すぐ ならない ことは ありません
 ・ものがたりの「きらきら」「ファンファーレ」の 効果音は その ものがたりの 調（ドの おと）に あわせるように した
   （これまでは 全部 ハ長調で、G や E♭ などの 曲と ぶつかって いた）。ファンファーレの あいだは 曲の 音量を すこし さげる
 ・音量：ミュート以外は ものがたり中 BGM が きえる しくみは そのまま
 ・調整：features.js の「const ST_DEF = {」（曲ごとの ドの おと・はやさ・コード・テーマ）と
         「const ST_MOOD = {」（ばめんごとの はやさ・楽器・音量）／全体の 音量は「const STP = {… vol:.3」

   コードの 音）・楽器の 音域（サンプルの ある 範囲）に もんだい なし
 ・ばめんの きりかわり（クロスフェード）・おなじ ばめんの くりかえしで やりなおさない・ミュート／ふっかつ・おわりで とまる・
   音が そろう まえの これまでの おとへの ふくかえ・しょうごとの よみこみ・効果音の 調あわせ
