■ 伴奏
 ・リズムゲーム 8曲 すべてに ドラム・ベース・ギター（かんたんの 曲は もっきんも）の 伴奏
 ・曲ごとに コード（ド・ファ・ソ など）を 入れて、そこから 自動で 演奏
   かんたん：やさしい 伴奏（ハイハットは 1拍ずつ、ギターは 2拍ずつ）
   ふつう：はずむ 伴奏（ハイハット 8分、ギターは ジャン・ジャ ジャン）
   せいじゃの こうしん：マーチ（小だいこが タタン）
 ・はじめの カウントは スティックの「カッ・カッ・カッ・カッ」（3・2・1 の 数字は そのまま）
 ・8小節ごとに タムの「タカ」、さいごは シンバルで ジャーン
 ・はやさ 50%・75% でも 伴奏が いっしょに ゆっくりに なる
 ・音ふは 伴奏の 時計に あわせて 動くので ずれない
 ・曲の 設定に「ばんそう：あり／ドラムだけ／なし」を 追加（えらんだ ものを おぼえる）
 ・まってくれる：正しい けんばんを おすまで 伴奏も 止まる
 ・一時停止・やめる で 伴奏も 止まる
