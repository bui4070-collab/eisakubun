■ バグ修正
 ・住民の おねがい「お医者さんの いえが あったら うれしいな」
   原因：ごほうび限定の「お医者さんの いえ」（0pt・ショップに ない）が おねがいの こうほに 入っていた。
   修正：ショップで ほんとうに 買える たてものだけを おねがいに する。すでに 出ている 同じ おねがいも じどうで きえる。
 ・漢字テストの けんさくバー（"板" → "板いたいtい"）
   原因：日本語入力の 変換ちゅうに、入力らんの 文字を 書きかえて いた。
   修正：変換ちゅうは けんさくせず、かくていした ときに だけ けんさくする。
■ プレゼント（ショップ画面の「プレゼント」ボタン）
 ・おくれる もの：かぐ（わたしの家に おいてある ものも OK）／のりもの／たてもの／かざり
   ※ ごほうび限定・イベント限定の ものは おくれない。たてものは まちから しまった ものが 対象
 ・おくる：ものを えらぶ（いちどに 5こまで）→ QRコードが でる → おともだちが よみとる → 「わたせたよ！」
   つくった しゅんかんに もちものから なくなる。わたせなかったら「やっぱり もどす」「おくり ちゅう」から もどせる
 ・うけとる：カメラで QRコードを よみとる。カメラが つかえない ときは
   「しゃしんで よむ」（QRの しゃしんを えらぶ）か「あいことばを いれる」（コピーした ことばを はりつける）
 ・ずかん：おくった ほうは ずかんから なくならない。うけとった ほうは ずかんに のる（のりもの・たてもの）
 ・おなじ QRコードは 1だいの 中で 1かいだけ。じぶんで つくった QRコードは うけとれない
 ・イラストは すべて イラスト（絵文字なし）。スマホ縦・iPad横 の どちらでも つかえる
 ※ カメラは https で ひらいた ときだけ つかえる（GitHub Pages なら OK）
