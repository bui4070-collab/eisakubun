 fl_C4 / E4 / A4 / C5 / E5 / A5 / C6 / E6 / A6 / C7（3〜4半音おき。あいだの 音は アプリで 高さを ずらす）

 ・pptx の 10ファイルを 1つずつ 音の高さを 測って 確認（高い 3音は こまかく 測りなおして C7・A6・E6 と 確認）
