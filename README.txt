■ 1. カクカクの 原因と なおしかた
 原因：曲の 音ふを ぜんぶ（トルコ行進曲は 約1400こ）、はじめに がめんの 部品（DOM）として つくり、
       ひとつ ひとつに GPU 用の レイヤー（will-change）まで ついて いた。
       まいフレーム 約1400この 部品に さわって いたので、音が ふえるほど（落ちてくるたびに）おもく なった。
       （曲が ながく なった v9.3 の lulu.・v9.4 の トルコ行進曲から めだつ。むかしの みじかい 曲では 気に ならなかった）
 なおし：がめんに でる 時間（落ちる 2.3秒いない）に なった 音ふだけ 部品を わりあて、
       ひいた・みのがした 音ふの 部品は つかいまわす（ひつような 部品は 50〜100こ くらいに）。
       音ふの うごかしかた・はんてい・スコア・★・ポイントは かえていません。
 ほかにも：
  ・キラキラ（ヒットの ひかり）が 一ぺんに でる かずを おさえた（いそがしい ところでは すくなめに）
  ・同じ フレームの おなじ「PERFECT!」ひょうじは 1かいだけ
  ・サビの えんしゅつ：がめんの ふちの ひかりを「ぬりなおし」の いらない 方式に／星の かずに じょうげん
  ・まいフレームの 全音ふ さがしを やめた（先頭の 音ふの いちを おぼえておく）

■ 2.「ちがう けんばん」を ひょうじしない
 ・まちがえて おした ときの もじを なくした。（けんばんが ほんのり ピンクに なるのと、コンボが きれるのは そのまま）
   ※ コンボも きらない ほうが よければ いってください

■ たしかめた こと（プログラムで 「にせの がめん」を つくり、実際の コードを うごかして 前と くらべた）
 トルコ行進曲（りょうて・おちてくる 音）を さいごまで あそんだ ばあい：
                         前（v9.4.1）      あと（v9.4.2）
   がめんの 部品の かず    約1,420〜1,590こ   最大 約80こ
   1フレームで さわる かいすう  平均 743 ／ 多い とき 1,414    平均 27 ／ 多い とき 65
   スタイルの かきこみ（ぜんぶ）  約755万かい       約24万かい
   ※ ブラウザの 実際の 速さは はかって いません（この 環境に ブラウザが ない ため）
 ・スコア・PERFECT/GREAT/GOOD/MISS・さいだいコンボは 前と まったく おなじ
 ・がめんに 見える 音ふの 位置・色・長さも まいフレーム 前と おなじ
   （トルコ行進曲・lulu.、おちてくる／がくふ、みぎて／りょうて、ゲーム／まってくれる／おてほん、
     ミスや ずれた タイミング・まちがい けんばん・ながおし・がめんの 大きさ へんこう を まぜて）
 ・remove_copyright.py で 著作権の 曲を けしても、この なおしは のこる（けした あとの ファイルも 前と おなじ ふうに うごく）
