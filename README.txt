■ 6つの しせつの BGM（楽器の 音を アプリが その場で 演奏）
 わたしのおうち：ローファイ・チルホップ。朝（5〜11時）・昼（11〜17時）・夜（17時〜）で コードと テンポが かわる
                 （夜は フルートの メロディー）。レコードの パチパチ音・こもった 音色
 がっこう／だいがく：ほうかご シティポップ（A→B→サビの 24小節）。フルートの メロディー、エレピ、ギターの カッティング、
                 サビで ホルンと ビブラフォン
 すいぞくかん：水の中の アンビエント。ハープの アルペジオ、チェロの 低音、ビブラフォンの ため息、あわの 音、大きな 響き
 どうぶつえん：サファリ・ボサノバ。ナイロンギター、クラリネットの メロディー、もっきんの あいの手、シェイカー
 かがくかん：ミニマル・エレクトロジャズ。ビブラフォン（3音）と もっきん（4音）の パターンが ずれて もようが かわる、
             B区間で バイオリン
 ホテル：ラウンジ・ボサジャズ（AABA 32小節）。テナーサックス、ピアノ、ウォーキングベース、ブラシ

■ しくみ
 ・テンション コード（maj7・m9・13 など）を ルートレスで、スウィング・ヒューマナイズ・リバーブ・左右の 位置
