まなびタウン おんがく：ギターの音（伴奏用・12ファイル）

■ アップロード先
 assets/audio/music/ に 12ファイル（gt_E2〜gt_Cs5）

■ 中身
 gt_E2 / gt_G2 / gt_As2 / gt_Cs3 / gt_E3 / gt_G3 / gt_As3 / gt_Cs4 / gt_E4 / gt_G4 / gt_As4 / gt_Cs5
 （3半音おき。あいだの 音は アプリで 高さを ずらして 鳴らす。As=A#、Cs=C#）
 → ギターの いちばん 低い 音（E2）から 和音に 使う はんいを カバー

■ 加工
 ・pptx の 37音（D2〜D5 半音ずつ ぜんぶ）を 取り出し、1つずつ 音の高さを 測って 確認（ならび順と 一致）
 ・最初の 無音を カット、長さ 3秒（さいごの 0.6秒で 小さく）、音量を そろえ（−1dB）
 ・mp3 モノラル 44.1kHz 96kbps（12ファイルで 約430KB）
