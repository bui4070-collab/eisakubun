【イラストの さしかえ方】
英語の 追加イラストは 1ことば = 1ファイル です。
assets/images/v48/en_（ことば）.webp を 同じ ファイル名で 上書きすると、その ことばの 絵が かわります。
例）peach の 絵 → en_peach.webp ／ police car は いまの パトカーの 絵（veh_police）を つかっています。
