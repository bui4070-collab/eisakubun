■ 入口
 こくご → 漢字の 画面の いちばん下に「百人一首」ボタン（教科カードにも「百人一首」を 追加）

■ ルール
 ・1回 10首。読み上げは 1文字 0.4秒（句の あいだは 1文字ぶん 休み）
 ・本番：上の句から 読み上げ、取り札（下の句・ひらがな）4まいから えらぶ。
   ポイント 30 ×まちボーナス。上の句を 読んでいる あいだに 取れたら はやどり +10 ×まちボーナス
   おてつき → その首は 0ポイント（正しい 札は とれる）。読み終わって 5秒で 時間切れ
 ・下の句を当てる：上の句を 見て 4択。20 ×まちボーナス。ヒント（番号・作者）／🔊で 上の句を 聞ける
 ・まちボーナス ＝ 1 ＋ 0.2 ×（まちLv − 1）  例：Lv1 ×1／Lv6 ×2／Lv11 ×3／Lv30 ×6.8
 ・暗記：れんぞく正解 3回で「覚えた」（緑）、1〜2回「もう少し」（黄）、0回「まだ」（灰）。まちがえると 0に もどる
 ・100首 ぜんぶ「覚えた」→ 20,000ポイント と 家具「百人一首の 金びょうぶ」（2×1マス・すてき度30・ちしき+2%）。1回だけ
 ・出題範囲：全部／1〜20／21〜40／41〜60／61〜80／81〜100（グラフの 下で えらぶ）
 ・グラフの 棒を タッチ → その歌（作者・本文・意味）を 表示、🔊で 聞ける

■ 読み上げ音声
 ブラウザの 音声読み上げ（日本語）を 使います。iPad は「Kyoko」などの 日本語の 声で 読みます。
 ヘッダーの 🔊 / 🔇 で オン・オフ。歴史的かなづかい（てふ・けふ・思ふ など）は 読みやすく 直して 読ませています。
 声が 出ない ときは、iPad の 消音スイッチ・音量、設定 → アクセシビリティ → 読み上げコンテンツ の 声を 確認してください。
