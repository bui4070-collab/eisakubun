■ 1. BGM：強弱と 単調さ ぼうし（ぜんぶの しせつ）
 ・小節ごとの 山（だんだん 大きく → 山 → すこし ひく）と、セクションごとの 大きさ（Aは ひかえめ・サビは 大きく）
 ・しせつに はいった 直後は イントロ（ドラム・ベースが あとから 入る）
 ・周回ごとに 楽器の かさなりが かわる（2周目は ビブラフォン・ギターが 目立つ／3周目は ストリングス・フルート…）
 ・おわりの 小節は すこし ゆっくり（ひと息）… すいぞくかん・ホテル・だいがく・びょういん
 ・強弱が ついた ぶん 小さく なった 平均を もどすため、曲ごとの 音量（gain）を 調整

■ 2. ゆうえんち：「カーニバル・ジャズ」に 作りなおし（40小節。イントロの あと 36小節が くり返し）
   イントロ（ビブラフォンの アルペジオ → スネアの ロール）
   A（ひかえめ）：クラリネット＋ビブラフォン、ウォーキングベース、ブラシ。小節の おわりで ひと呼吸
   A'（すこし 大きく）：フルート＋もっきん、ホルンの うらうち、ピアノの ひとはしり
   ブリッジ（ラテン）：まっすぐな 8ぶん・クラーベ・トゥンバオ・サックス。だんだん 大きく → ストップ タイム（ロールだけ）
   シャウト（いちばん 大きく）：ストライドピアノ・ホルンの スタブ・クラリネット＋フルート＋もっきん＋サックス。クラッシュ。さいごは ストップ
   タグ（ぐっと 小さく）：ビブラフォン＋フルート → ゆっくりに なって また A へ
   周回ごとに メロディーの 楽器が かわる（1周目 クラリネット／2周目 フルート／3周目 サックス…）
   和音は お洒落な 形（Cmaj9・G7sus4・Db9（裏コード）・Ebdim7・E7#9・A13・G13b9・C6/9）

■ 3. のうりょくの じょうげん（レア度べつ）
   ふつう 50／ちょっとレア 100／レア 150／ちょうレア 300（app.js の AB_CAP で かえられる）
   ・どの のうりょくも これを こえない（★ランクの ボーナスを 入れても こえない）
   ・上限に なると がめんに「MAX」。能力の実は MAX の のうりょくには 使えない（実は へらない）
   ・もともと こえていた 住民は 上限に そろえる
   ・住民の がめんで 上限が 分かる（バーは 上限が 100%）

■ 4. トルコ行進曲を ながく（約20秒 → 約1分3秒）
   はじめの テーマ（2回）→ 行進の 部分（イ短調）→ ハ長調の 明るい 部分 → テーマ → コーダ
   ※ はじめの テーマは 今までの まま。あとの 部分は 同じ 雰囲気の アレンジです（原曲の 楽譜どおりでは ありません）

■ 5. リズムゲームに 曲を ふやした（12きょく → 20きょく。ぜんぶ 著作権の きれた 曲）
   かんたん：ホットクロスバン／フレール・ジャック／ゆかいな まきば／ボートを こごう
   ふつう：ハッピーバースデー／きよしこのよる／うんめい（はじめの ぶぶん）
   むずかしい：エリーゼのために
   ・「ぜんぶ」の ならびを むずかしさ順に（かんたん → ふつう → むずかしい → ちょう むずかしい）
   ・新しい 曲は 同じ むずかしさの 最後の 曲を ★1 で クリアすると ひらく
