かわった ところ:
1. ホームの ロゴ：たかさ 88px → スマホ 最大70px／iPad 最大84px。
   ロゴの みぎに「BGM・せってい」、その 下に「ポイント・すいしょう」を ならべて、かさならないように した。
2. iPad よこ（はば900px いじょう・よこむき）レイアウト
   - がっこう／だいがく：ひだり＝なかまの イラスト（スクロールしても のこる）、みぎ＝ミッション・じゅぎょう（こうざ）・きろく。
     じゅぎょう・けっか・研究ノートの カードは はば 760px まで ひろげる。
   - どうぶつえん／すいぞくかん：
     トップ＝ひだりに イラスト、みぎに「きょうの けんがく」「ずかんの あつまりぐあい（エリアごと）」と あるく・ずかん ボタン。
     あるく＝よこいっぱいに ひろがる。クイズ＝ひだりに いきもの、みぎに もんだい。けっか・ずかんも よこ むけに。
3. がめんの むき
   - スマホ：たて こてい（よこに すると「スマホを たてに してね」がめん）
   - iPad：よこ こてい（たてに すると「iPadを よこに してね」がめん）
   - パソコン（マウス）は こていしない。
   ※ iPhone／iPad の Safari は ウェブページから かいてん そのものを とめることが できないため、
     ちがう むきの ときは 「まわしてね」がめんで おおって つかえないように しています。
     Android の ホーム画面アプリ・全画面では ほんとうに こていされます。
