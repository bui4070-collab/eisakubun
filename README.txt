■ 修正・改善
 1) ながい 音ふ（2拍 いじょう）
   ・おしている 間は 音ふが 消えず、判定ラインで ちぢんでいく（光って ゆれる）。けんばんも 光りつづける
   ・おしている 時間で スコア ＋（1拍 40てん）、さいごまで おせたら「ながおし OK!」＋50
   ・ゲームの ポイントにも ボーナス（1拍 0.5pt × まちLv、★1 いじょう）。結果に「ながおし ○拍」
 2) PERFECT／GREAT／GOOD の ときに キラキラ（PERFECT は 光の わ＋星、ながおし OK は 大きな キラキラ）
 3) おちてくる 音ふの 白い 枠を なくした
 4) がくふモード（音ふ だけで ひく）
   ・曲の 設定「みかた：おちてくる 音／がくふ（音ふ だけ）」
   ・ト音記号の 五線に 音ふが 右から 左へ ながれ、たての 線で ひく
   ・けんばんは 名前も 色も なし（ドの けんばんに 小さく「ド」だけ）
   ・4分・8分（はた つき）・2分（白い 玉）・全音ふ、♯、加線、ながい 音は うしろに 帯
 5) 【バグ】きょうの ミッション「パーフェクトを とろう」：おやつや 本の 倍率が かかると
   たっせいに ならなかった → 修正（ほかの パーフェクトでも たっせい）
