■ 今回の 変更
1. 空港の 文字・問題を 漢字に（ふりがな つき）
   ・ふりがなは「ぜんぶ／むずかしい字／なし」を くうこうの 中で きりかえ。はじめは「ぜんぶ」
   ・問題は 384問 すべて 漢字（空港コード・難読 空港名・国と首都・時差・飛行機 など）
2. 空港の イラストを キャラクターごと 描きなおし（同じ ファイル名で さしかえ）
   ・スズメ（管制官）・ナマケモノ（チェックイン係）・ペリカン（機長）を あたらしく 描き、絵の 中に 登場
   ・トップ画面は 全面イラスト。スマホ縦も iPad横も 絵が 画面いっぱい（iPadは 左右に ぼかしの 背景）
   ・イラストの スズメ・ナマケモノ・ペリカンを タッチ → しゃべる／チェックイン／行き先
   ・プラチナランクは ペリカンが 特別な 帽子の 絵に かわる
3. モデルの 町を ご用意の 4まい の 絵に さしかえ（南の島・雪山の町・森の町・都会の町）＋ 雲の上の町（プラチナ）
   ・どの 町も 全面イラスト。スマホ縦は 指で 動かして 見わたせる（「全体」ボタンで ぜんたい表示）
   ・光る マークの 施設を タッチ → 施設の きのうを つかえる
     遊園地・総合病院・大きな駅・大学・温泉旅館・ショッピングモール・植物園・コンサートホール・噴水広場・
     博物館・図書館・公園・郵便局・パン屋（カフェ）・畑・みなと・天文台（展望台）・キャンプ場・お城（ちいさなお城）
   ・まちづくりに まだ おいて いない 施設でも つかえる（ここだけの 一時的な 施設で、町には のこらない）
   ・「グレードアップ」は 出ません。空港の イラストを タッチすると 帰りの便へ
4. 友だちの 町：その 友だちの 町に ある 施設も タッチして つかえる（光る マーク）
5. お土産
   ・買う → 「お土産袋」に 入る（1回の 旅で 5こまで／同じ ものを くり返し 買える）
   ・食べる：おやつと 同じ。しばらく 勉強の ポイントが ふえる（ココナッツ・フルーツ・木の実・キャンディ・ケーキ など）
   ・かざる：「わたしの家」の もちものに 入る。上から 見た イラスト（ft_sv_01〜24）つき
   ・お土産袋は 空港トップの ヘッダー・訪問先・結果・パスポートから ひらける
6. まちづくり画面を ときどき 横ぎる 飛行機＋スズメは なくしました
7. 文字が ワクから はみ出さないように（スマホ縦 360〜430px／iPad横 1024〜1366px を じどうチェック）
