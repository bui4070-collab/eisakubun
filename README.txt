■ 変更点
 ・トップ画面（スマホ縦）
    背景イラストを 画面の 上の 半分（高さの 50%）まで 大きく 表示
    「科学見習い」の メダルの 枠と「今日の不思議（ポイント×2）」の 枠を 横ならびで 小さく 表示
    6つの ゾーンは イラストを 枠ぜんぶに 使い、名前と ☆は 下の 暗い 帯の 上に 白い 文字で 表示（キャラクターの 顔に かぶらない）
    ボタン・文字を ぜんたいに 小さく して、画面が 小さくても スクロールで 下まで 見られる
 ・ゾーンの 進み具合の 表示を ○○○○ から ☆☆☆☆（クリア済みは ★）に 変更
 ・文字を 基本的に 漢字に 変更
    ひらがなで 書いて あった 言葉（問題・実験・今日・不思議・電気・磁石・車・光・音・宇宙・命・体・結果・全部・一番 など）を、表示する ときに 自動で 漢字に する
    ルビは 漢字に 自動で つく（右上の「ルビ」ボタンで 一部／全部／なし を きりかえ）
    文の 区切りの 空白を 取って、ふつうの 日本語の 文章に 変更
    数の あとの かぞえかたも 漢字に（2個・3回・5問・10秒 など）
 ・ルビの ボタンの 表記を「ふりがな」から「ルビ」に 変更
