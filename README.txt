まなびタウン おんがく：けんばんハーモニカの音（33ファイル）

■ アップロード先
 assets/audio/music/ に 33ファイル（mh_F3〜mh_D6）
 ※ ピアノ（pf_ 13ファイル）と 同じ フォルダ。合計 46ファイルで 50ファイル以内

■ 中身
 mh_F3 から mh_D6 まで 半音ずつ ぜんぶ（33音）。けんばんハーモニカ（32けん F3〜C6）の はんいを すべて カバー
 （Cs=C#、Ds=D#、Fs=F#、Gs=G#、As=A#）

■ 加工
 ・pptx の 38音を 取り出し、1つずつ 音の高さを 測って 確認（ファイルの ならび順と 一致）
 ・ハーモニウムを 1オクターブ 上げて けんばんハーモニカの 高さに（明るい 音に なります）
 ・最初の 無音を カット、長さ 3.5秒（のばす 音は アプリで くりかえし 鳴らす）、音量を そろえ
 ・mp3 モノラル 44.1kHz 128kbps（33ファイルで 約1.9MB）
 ・F3 より 低い 5音（C2〜E2 を 上げた もの）は けんばんハーモニカに ない 音なので 使いません
