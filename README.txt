■ できるようになったこと
 ・ホテルをタッチすると、豪華な外観イラスト（スマホ縦用／iPad横用で別の絵）がまちづくり画面の前面に出ます。
   光っている窓をタッチすると、その部屋に入れます（下の部屋カードからも入れます）。
 ・部屋は8種類。グレード ★0：スタンダード・和室／★1：オーシャンビュー・森のコテージ
   ★2：スカイテラス・雪見／★3：スイート・ロイヤルスイート
   部屋ごとに専用イラスト（縦用・横用）があり、来やすいお客さんの種類が変わります。
 ・来る確率（ふつう／ちょっとレア／レア／ちょうレア）は仕様書5-2どおり。
   ちょうレアはロイヤルスイートでも3％。「とくべつ」は来ません。
 ・お客さんがチェックアウトすると、部屋は30分そうじ中になり、その後に次のお客さんが来ます
   （ホテルが2つ以上あると、そうじ時間が短くなります）。
 ・話しかける（10分に1回 ＋1）、おみやげ（好きな物 ＋2／それ以外 ＋1、1日2回まで）、
   畑のやさい（＋1）、ルームサービス（＋1、1日1回）で仲良し度が上がります。
   話しているうちに、好きな物のヒントがわかります。
 ・仲良し度の上限はレア度で 3〜5。満タンで「仲良し」になり、仲良しリスト（最大10人）に入ります。
 ・レターを使ったとき、仲良しのお客さんは仕様書8章の確率で優先して来てくれます。
 ・ホテルのお店（ホテル限定）：おみやげ6種／スペシャル4種
   （ルームサービス・ゴールドベル・ホテルの招待状・仲良しレター）。
   「家具・かざり」タブから、これまでの家具のお店にも行けます。
 ・ちょうレアのお客さんが来たときは、金色の特別演出が出ます。マップのバッジも ✨ になります。
