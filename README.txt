■ ① おやつの ていあん
 ・おやつを たべて いない（倍率が 出て いない）ときに、勉強を はじめると ていあんが 出る
   出る ところ：べんきょう画面（教科えらび・漢字・さんすう・しゃかい・りか・えいご・ぶんしょう・プログラミング）
               施設を ひらいた とき（がっこう／大学・えき・どうぶつえん・病院・ゆうえんち・空港・科学館・スタジアム・つり・百人一首）
 ・もっている おやつの 中で いちばん 倍率が 高い もの（同じ なら 長く きく もの）を ていあん
 ・その まま「○○を たべる」で たべられる／「ほかの おやつを えらぶ」で おやつ一覧
 ・「いまは たべない」→ 30分は 出ない、「きょうは もう 出さない」→ その日は 出ない
 ・おやつを 1つも もって いない ときは 出さない
 ・施設の 問題で もらう ポイントにも おやつの 倍率が かかる ように（これまで 対象外だった）

   科学館（クイズ・実験の 問題）・スタジアム・タワー・電車クイズ・百人一首・住民／まちの クイズ・つり・ほしの クイズ など
