■ しくみ（v9.0 から 変えた ところ）
 ・3拍子（ワルツ）の 小節に 対応（S.beats）、曲ごとの 音量 調整（gain）、1回だけ ならす 曲（once）
 ・しせつの 中で 2きょく 以上 ある ときは 1周ごとに つぎの 曲へ（FPL）。つぎの 曲の 音は 先に よみこむ
 ・だいがく と がっこうは 別の 曲に（だいがく ＝ #sc631 の bgU634）
 ・音量は いつもの BGM の きまりの まま（クイズ・じゅぎょう中は 小さく、BGM オフでは 鳴らない、おんがくの 勉強中は 止まる）
 ・音が そろわない ときは これまでの BGM.mp3（ゆうえんちは BGM_yuenchi.mp3）、スタジアムは これまでの 音の まま
 ・スタジアムは 試合に はいった とき すぐ 鳴るように、スタジアムの ある まちでは 9秒後に 音を よみこむ

■ なおした もの（今回 見つけた）

   （ファンファーレが おわって 9秒 たったら かならず BGM が もどる）
