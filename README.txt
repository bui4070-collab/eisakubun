まなびタウン v7.5 STEP1（キャラ画像の chara 集約 ＋ ランク専用イラストの しくみ）

■ すすめかた（この順番で）
 1. tools/move_chara_images.bat を リポジトリの 中で ダブルクリック
    （または PowerShell で  tools\move_chara_images.ps1  を 実行。 -Copy を つけると 元ファイルを のこす）
    → res_*（住民）／scu_*（特別イラスト）／acc_*（ぼうし・かざり）の 画像 227まいが
       assets/images/chara/ に ひっこし ＆ 〈キー〉.webp（scu は .jpg）に 名前が そろいます。
    ※ 元の image_xxx_xxxx.webp は なくなります（残したい時は -Copy）。
 2. GitHub Pages に アップロード（合計 3ファイル）
    ・js/facilities.js を 上書き
    ・assets/images/chara/res_cat_r3.webp
    ・assets/images/chara/res_cat_r5.webp
    （ひっこした 227まいも リポジトリ側で 反映してください。一度に 50ファイルを こえる 場合は 分けて OK）

■ ランクの 絵の ルール
 ふつうの子 ：★1〜2 ＝ もとの絵（res_〈id〉）／★3〜4 ＝ res_〈id〉_r3／★5 ＝ res_〈id〉_r5
 超レアの子 ：★3〜4 ＝ res_〈id〉_r3／★5 ＝ res_〈id〉_r5（res_〈id〉 は ずかん用）
 ・新イラストが ある子 → 新イラストに 切りかわる（ぼうし・マント等の かさねがけは しない）
 ・まだ ない子     → これまで通り（もとの絵＋かざり）。だから ステップの とちゅうでも 動きます
 ・★4 は 専用の 絵を つくらないので ★3 の 絵（メッセージは「あと ★1つで ゴージャス！」に 変更）

■ STEP1 で できた 子
 ネコ（★3 / ★5）…… しくみの 動作確認用
