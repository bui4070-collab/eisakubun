まなびタウン おんがく：ベースの音（伴奏用・12ファイル）

■ アップロード先
 assets/audio/music/ に 12ファイル（bs_E1〜bs_Cs4）

■ 中身
 bs_E1 / bs_G1 / bs_As1 / bs_Cs2 / bs_E2 / bs_G2 / bs_As2 / bs_Cs3 / bs_E3 / bs_G3 / bs_As3 / bs_Cs4
 （3半音おき。あいだの 音は アプリで 高さを ずらして 鳴らす）
 → ベースの いちばん 低い 弦（E1）から 伴奏に 使う はんいを カバー

■ 加工
 ・pptx の 17音（Cs1〜Cs5、3半音おき）を 取り出し、1つずつ 音の高さを 測って 確認
   ※ 低い 4音（Cs1・E1・G1・As1）は ふつうの 測り方では 低すぎて 測れないため、倍音から 確認
 ・最初の 無音を カット、長さ 2.5秒（さいごの 0.5秒で 小さく）、音量を そろえ（−1dB）
 ・mp3 モノラル 44.1kHz 96kbps
